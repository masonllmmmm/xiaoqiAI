# 文件批量打包压缩工具（v12）

纯前端单文件网页工具：把大量文件装进一个文件夹，按编号正确排序（01→38）、批量加序号，打包成 ZIP 后存到本机或发给微信好友。手机、电脑双端可用，断网也能用。

标题下方显示版本号（如 v12），可确认是否为最新版。

## v12：公告弹窗全屏化 + 双端适配

- **真全屏铺满**：`100vw/100vh`，并用 `dvh` 规避手机地址栏收缩导致的高度抖动
- **PC**：居中卡片（最大 380px），半透明遮罩 + 背景模糊，点右上角 ✕ 或「我知道了」关闭
- **手机（≤600px）**：内容盒撑满整屏、圆角去掉，图标与字号放大，按钮自动落到屏幕底部拇指区
- **安全区适配**：关闭按钮避开刘海（`env(safe-area-inset-top)`），底部按钮避开 Home 条（`env(safe-area-inset-bottom)`）
- **锁定背景滚动**：弹窗存在时背景不滚动，关闭后自动恢复
- **关闭方式不变**：仍必须点右上角 ✕ 或「我知道了」，点遮罩空白、按 Esc 均不会关闭

## 核心功能

### 排序与批量加序号

- 「🔢 按编号排序」：按序号升序，列表左侧蓝色徽章 01、02…
- 「1️⃣ 排序并加序号 01→38」：先排序，再在文件名最前面加 `01_`、`02_` … `38_`
- 自动识别编号与位数，显示范围与缺号（如 ⚠️ 缺号：07、15）
- 序号位置：最前面（带分隔符）/ 最前面（紧贴）/ 末尾 / 替换原名
- 分隔符默认 `_`，可改 `-` 或留空；起始序号、序号位数（1~4 位）可调
- 排序方式：编号升降序、文件名自然序、大小、修改时间
- 只改压缩包内的名字，不动原文件

### 打包与分享

- 不挑文件类型；电脑端可拖入整个文件夹（保留目录结构）
- 自动建立顶层文件夹，解压后不散落
- 智能压缩：几乎都是 PDF / 图片 / 视频时自动切「仅打包」
- 完成后「💬 发微信好友 / ⬇️ 存到本机 / 📱 打开微信」
- 微信内置浏览器自动识别并引导到系统浏览器
- 全程本地处理，文件不上传服务器

## 更新后看不到新功能？

看标题下方是否显示 **v12**；电脑 `Ctrl+F5`（Mac `Cmd+Shift+R`）；手机用无痕窗口；或网址后加 `?v=12`。GitHub Pages CDN 刷新需等 2～10 分钟。

## 微信相关限制

网页无法直接指定发给某个微信好友，也无法读取聊天记录里的文件——这是微信的限制。本工具调系统分享面板选微信发送；不支持时先存本机再手动发。

## 部署到 GitHub Pages

1. 新建 Public 仓库，例如 `zip-tool`
2. 上传 `index.html`、`.nojekyll`
3. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)` → Save
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/zip-tool/`

需 Public 才有免费 Pages；Pages 自带 HTTPS，系统分享面板才能调用。备选：Vercel / Netlify / Cloudflare Pages。

## 说明

- 上限受设备内存限制，手机一般 1GB 以内没问题
- 微信单文件传输上限约 100MB，超出建议分批打包
