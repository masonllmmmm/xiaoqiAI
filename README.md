# 文件批量打包压缩工具

纯前端单文件网页工具：把大量文件（PDF / Word / 图片 / 视频 / 任意格式）装进一个文件夹，自动按编号排序、批量加序号，打包成 ZIP 后存到本机或直接发给微信好友。手机、电脑双端可用，断网也能用。

## 核心功能

### 编号排序与批量加序号

- **自动识别编号规律**：文件名末尾的数字会被拆成「公共前缀 + 序号」。例如 20261081201、20261081202 … 20261081238，自动识别为前缀 `202610812` + 2 位序号，并标出范围与缺号。
- **一键加序号**：点「1️⃣ 排序并加序号 01→38」，先按编号升序排好，再在每个文件名最前面加 `01_`、`02_` … `38_`，结果如 `01_20261081201.pdf`。
- **序号位置**可选：最前面（带分隔符）/ 最前面（紧贴原名）/ 末尾 / 替换原名
- **分隔符**可自定义，默认 `_`，可改为 `-` 或留空
- 起始序号、序号位数（2/3/4 位）可调；位数不够会提前拦下并提示
- 排序方式还支持：按编号升降序、文件名自然序、大小、修改时间
- 只改压缩包内的名字，不会动设备上的原文件

### 打包与分享

- 不挑文件类型；电脑端可拖入整个文件夹（保留目录结构）
- 自动建立顶层文件夹，解压后不散落
- 智能压缩：几乎都是 PDF / 图片 / 视频等已压缩格式时自动切「仅打包」
- 完成后出现「💬 发微信好友 / ⬇️ 存到本机 / 📱 打开微信」
- 微信内置浏览器自动识别并引导到系统浏览器
- 全程本地处理，文件不上传服务器

## 微信相关限制

网页无法直接指定"发给某个微信好友"，也无法读取聊天记录里的文件——这是微信的限制。本工具的做法：调系统分享面板选微信发送；不支持时先存本机再手动发。微信里的文件需先「用其他应用打开」/「保存到手机」。

## 部署到 GitHub Pages

1. 新建 Public 仓库，例如 `zip-tool`
2. 上传 `index.html`、`.nojekyll`
3. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)` → Save
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/zip-tool/`

需 Public 才有免费 Pages；Pages 自带 HTTPS，系统分享面板才能调用。备选：Vercel / Netlify / Cloudflare Pages。

## 说明

- 上限受设备内存限制，手机一般 1GB 以内没问题
- 微信单文件传输上限约 100MB，超出建议分批打包
